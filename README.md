Musemo – Museum Management Information System

Overview
Musemo is a Java-based Museum Management Information System designed to streamline museum operations—from managing collections and exhibitions to visitor engagement and reporting. It's a static (non-web) desktop app built with Java. 

Features
1. Add, edit, delete museum objects with metadata (title, author, era, location, etc.)
2. Organize and schedule exhibitions
3. Generate reports on visitors, objects, and loans
4. Persistent storage via flat files or embedded database
5. Simple, intuitive Java Swing UI with modular code design

Built-On:
1. Language: Java SE
2. UI: Swing/AWT
3. Data: Local storage (e.g., JSON/XML or embedded DB like SQLite)
