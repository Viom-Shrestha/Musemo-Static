# 🏛️ Musemo - Museum Management Information System (Static Version)

**Musemo** is a Java Swing-based desktop application developed in **NetBeans IDE**, focused on backend operations for museum administration. The project streamlines internal museum tasks like managing visitors, artifacts, and archival processes through an interactive GUI using **Swing** and **AWT**.

## 🔧 Features

### 🧍 Visitor Management
- Add visitors to a queue system
- Display real-time visitor queue using `JTable`
- Dequeue (next visitor) and archive records
- Real-time visitor count tracking

### 🖼️ Artifact Management
- Add, update, delete (CRUD) museum artifacts
- Search and sort artifacts by name/type/etc.
- Implements multiple sorting algorithms:
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Binary Search (for fast lookup)
- Display artifact data in `JTable`

## 🛠️ Technologies Used
- **Language:** Java SE
- **IDE:** NetBeans
- **UI:** Swing, AWT
- **Data Handling:** In-memory data structures and file-based storage
